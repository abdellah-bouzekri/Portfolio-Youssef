# Youssef — Motion Designer Portfolio (React + Tailwind CSS)

A clean, modern, and straight-to-the-point portfolio website built with modular React components and Tailwind CSS for **Youssef**, a 25-year-old motion designer with 3.5 years of freelance experience, holding a Baccalauréat Scientifique and an OFPPT Technicien Spécialisé en Multimédia diploma.

## 🚀 Quick Start

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```
